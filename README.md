# Budget Tracker

## Project Description

This project is a Budget Tracker created using HTML and CSS. The application allows users to view an expense form and an expense table in a clean and organized layout.

For the Visual Design Challenge, I improved the existing Budget Tracker by applying a consistent color palette, custom typography, table styling, form styling, and the CSS Box Model.

## Color Palette

I used a professional blue and white color palette.

* Dark blue for headings, buttons, and table headers
* Light blue-gray for alternating table rows and borders
* Light background for the page
* White for the main content cards

## Typography

I used Google Fonts to improve the appearance and readability of the application.

* Montserrat is used for the main headings and table headings.
* Open Sans is used for body text, labels, form elements, buttons, and table content.

## Add Expense Form

The Add Expense section contains the existing expense form. CSS was used to improve the appearance of the labels, input fields, category selection, and button.

Padding, margins, borders, and rounded corners were added to make the form clean and user-friendly.

## Expense Table

The expense table displays expense information such as the name, amount, category, and date.

The table includes:

* A colored header
* Cell padding
* Borders
* Alternating row colors
* Rounded corners
* Hover effects

## CSS Box Model

The CSS Box Model was used throughout the project.

* Margin separates different sections.
* Padding creates space inside cards, forms, inputs, and table cells.
* Borders define the different areas of the application.
* Border-radius creates rounded and modern-looking sections.

## Files

## Conclusion

The Visual Design Challenge improved the original Budget Tracker by making it more organized, readable, consistent, and visually appealing while keeping the existing HTML structure and functionality.
